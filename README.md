# AktionsDeck Landau

Web-App (PWA) für Klima-Gruppen in Landau: Material, ToDos, Projekte, Posts und Kalender.

- Oberfläche: reines HTML, CSS und JavaScript (ES-Module), läuft auf GitHub Pages.
- Daten: Google Sheet, erreichbar über ein Google Apps Script (Ordner `apps-script/`).
- In diesem Repo stehen keine PINs, Hashes oder Geheimnisse.

## Ordner

- `css/` Gestaltung
- `js/` Programmcode
- `icons/` App-Icon
- `apps-script/` Kopie des Google-Skripts
- `docs/` Notizen
